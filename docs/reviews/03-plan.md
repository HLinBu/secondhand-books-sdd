## AI 推測或錯誤的地方

- P-01 至 P-08 是 agent 從規格書其他段落找出、但核心資料表沒有列出的資料；補在哪個實體由 agent 決定。
- V-01 至 V-05 的值，以及 AI-11 的圖片數值，都由 agent 提出，審查者全部照建議接受。
- data-model 與 contracts 中標為「設計決定」的項目由 agent 決定，包括：
  - Email、ISBN 不可重複
  - 一筆訂單一筆物流紀錄
  - P-08 與 AI-07 合併成「站內通知」實體
  - 後台操作紀錄只能新增
  - 搜尋、書籍頁、刊登詳情不需登入即可瀏覽
- research 的 R-02 至 R-10 由 agent 提出，包括 Django 5.2 LTS、條件更新防止重複售出、期限處理用管理指令、自己寫 CSS 不用前端框架。
- 錯誤：系統操作契約第一版把搜尋、篩選、查看書籍頁的執行者寫成「任何人」，提交審查前改為「買家」；改為實作後，頁面契約依設計決定開放未登入瀏覽。
